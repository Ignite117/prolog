 ЛР1. Упражнение 1.3 — родственные отношения
======================================================
  является_матерью(X):
      александра
      виктория
      луиза
      (путей вывода 7, различных ответов 3)

  является_отцом(X):
      альберт
      кристиан
      эдуард
      (путей вывода 7, различных ответов 3)

  является_сыном(X):
      артур
      георг
      эдуард
      (путей вывода 6, различных ответов 3)

  является_дочерью(X):
      александра
      алиса
      беатриса
      дагмар
      (путей вывода 8, различных ответов 4)

  является_сестрой(X, артур):
      алиса
      беатриса

  дедушка(X, георг):
      альберт
      кристиан

  бабушка(X, георг):
      виктория
      луиза

  общие_родители(эдуард, X):
      алиса
      артур
      беатриса
      эдуард

  тётя(X, георг) — книжное правило, с ошибкой:
      александра
      алиса
      беатриса
      дагмар

  тётя_исправленная(X, георг):
      алиса
      беатриса
      дагмар

  Почему у одного ответа бывает несколько путей вывода
  (упражнение 1.2 книги):
      является_матерью(виктория) доказывается четырьмя
      способами — по одному на каждого её ребёнка, так как
      цель мать(виктория, _) согласуется с четырьмя фактами.
      Ответ при этом один и тот же: Prolog перебирает пути,
      а не отличает ответы друг от друга.

  Ошибка в книжном правиле тётя/2:
      оно не требует различны(X, Z), поэтому при X = Z
      превращается в «женщина X — родитель Y».
      Отсюда александра в ответе: она мать георга, а не тётя.


======================================================
 ЛР2. Упражнение 3.1 — списки и сравнение слов
======================================================
  Исходный предикат меньше/2 (строго меньше):
      меньше(арбуз, букварь)                         да
      меньше(ветер, автомобиль)                      нет
      меньше(картина, картина)                       нет

  После упражнения 3.1 — меньше_равно/2:
      меньше_равно(арбуз, букварь)                   да
      меньше_равно(картина, картина)                 да
      меньше_равно(пар, паровоз)                     да
      меньше_равно(алфавитный, алфавит)              нет

  Прочие операции над списками:
      сорт_слова([слон,арбуз,картина,арбуз,букварь]) -> [арбуз,арбуз,букварь,картина,слон]
      присоединить([a,b,c],[d,e],X)                  -> [a,b,c,d,e]
      обр([1,2,3,4,5],X)                             -> [5,4,3,2,1]
      длина([1,2,3,4,5],X)                           -> 5
      сумма([10,20,30],X)                            -> 60
      максимум([3,17,5,2],X)                         -> 17
      удалить(a,[a,b,a,c,a],X)                       -> [b,c]


======================================================
 ЛР3. Ханойские башни и динамическая база данных
======================================================
  Вариант из книги, 3 диска — ходы печатаются сразу:
[переместили диск со штыря,левый,на штырь,средний]
[переместили диск со штыря,левый,на штырь,правый]
[переместили диск со штыря,средний,на штырь,правый]
[переместили диск со штыря,левый,на штырь,средний]
[переместили диск со штыря,правый,на штырь,левый]
[переместили диск со штыря,правый,на штырь,средний]
[переместили диск со штыря,левый,на штырь,средний]

  Вариант с динамическими фактами, 3 диска:
      план для 3 дисков построен
      сделано 7 ходов, теоретический минимум 2^3-1 = 7
      ход 1:     левый -> средний
      ход 2:     левый -> правый
      ход 3:     средний -> правый
      ход 4:     левый -> средний
      ход 5:     правый -> левый
      ход 6:     правый -> средний
      ход 7:     левый -> средний
      ходы, затронувшие правый штырь: [2,3,5,6]

  Рост числа ходов с числом дисков:
      план для 1 диска построен
      сделано 1 ход, теоретический минимум 2^1-1 = 1
      план для 5 дисков построен
      сделано 31 ход, теоретический минимум 2^5-1 = 31
      план для 10 дисков построен
      сделано 1023 хода, теоретический минимум 2^10-1 = 1023

 ЛР5. Грамматики DCG, phrase, упражнение 9.1
======================================================
  Разбор предложений предикатом phrase/2:
      phrase(предложение, [the,man,eats,the,apple])  да
      phrase(предложение, [the,man,sings])           да
      phrase(предложение, [man,the,eats])            нет
      phrase(группа_существительного, [the,man])     да

  Порождение предложений той же грамматикой (первые 6):
      [the,man,eats]
      [the,man,sings]
      [the,man,eats,the,man]
      [the,man,eats,the,apple]
      [the,man,eats,the,song]
      [the,man,eats,a,man]

  Дерево разбора (грамматика с доп. аргументом):
      предложение(гс(опр(the),сущ(man)),гг(гл(eats),гс(опр(the),сущ(apple))))

  Упражнение 9.1 — трансляция грамматических правил:
      предложение-->группа_существительного,группа_глагола
        =>  предложение(A,B):-группа_существительного(A,C),группа_глагола(C,B)
      определитель-->[the]
        =>  определитель(A,B):-присоединить([the],B,A)
      группа_глагола-->глагол,группа_существительного
        =>  группа_глагола(A,B):-глагол(A,C),группа_существительного(C,B)
      существительное(сущ(man))-->[man]
        =>  существительное(сущ(man),A,B):-присоединить([man],B,A)
